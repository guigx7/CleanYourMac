# Relatório de paridade — CleanYourMac 0.1.0 × CleanMyMac 5.7.2

Data: 2026-10-20, 16:13 (UTC−3). macOS 26.6.2, Apple Silicon.

## Método
1. No CleanMyMac, só **análise**: Recomeçar → Analisar → Revisar Todos os Detritos,
   tudo via Acessibilidade (`scripts/re/collect-baseline.sh`, que recusa qualquer botão
   de limpeza). Nada foi limpo no CleanMyMac.
2. Conversão da UI para JSON: `scripts/parity/ax_to_baseline.py` →
   `docs/re/parity/baseline-2026-10-20-final.json` (14 grupos, 350 itens).
3. Logo em seguida: `cym scan --json` (mesmo disco, mesmo usuário, sem admin).
4. `scripts/parity/compare.py` com tolerância de `max(2%, 5 MB)` por grupo.

## Divergências explicadas
1. **Cache do sistema:** o CleanMyMac mede com um helper root instalado. O CleanYourMac
   mede pelo botão "Medir caches do sistema" (uma senha de administrador, `du -sk` em lote).
   Pelo CLI, sem senha, os dois itens (`com.apple.iconservices.store`,
   `com.apple.coresymbolicationd`) são ilegíveis e ficam de fora — como no CleanMyMac sem helper.
2. **CleanMyMac.app em Binários universais:** o CleanMyMac pula apenas a si mesmo. Para o
   CleanYourMac ele é um app de terceiro como outro qualquer (o CleanYourMac pula o próprio bundle).
3. **Registros do CleanMyMac em `~/Library/Logs/CleanMyMac*`:** mesma razão do item 2.

## Correções feitas a partir desta comparação
- Acúmulos de IA passaram a usar o tamanho **alocado** (a spec supunha lógico; a baseline bateu
  no alocado: Claude 246,3 × 246 MB, Claude Code 587,7 × 588 MB).
- Lista de exclusões do cache do usuário revisada: `clang`, `com.apple.dt.xcodebuild`,
  `org.swift.swiftpm`, `com.apple.dock` e `MonogramPosterExtension` passam a aparecer (não
  existiam na primeira baseline); `IMDPersistenceAgent`, `IMTransferAgent` e `ThumbnailsAgent`
  saem (o CleanMyMac os ignora); `~/Library/Logs/CoreSimulator` sai dos registros.
- Teclado: só o primeiro idioma de cada fonte protege `.lproj` (o teclado "Brazilian - Pro"
  lista 95 idiomas).

## Não verificado por observação
Grupos vazios nesta máquina (Mail, Lixos, Backups iOS, Versões de Documentos, Usuários apagados,
Modelos locais, Preferências defeituosas) seguem as specs e os testes de fixture, sem comparação
com itens reais. A limpeza em si não foi comparada (decisão do design: só simulação).
